# Home

Welcome to **Probato**.

Probato is an **opinionated and declarative framework for functional test automation**, designed to bring structure, predictability, and observability to automated testing projects.

This home section introduces the framework, its goals, and its conceptual architecture, helping you understand **what Probato is** and **how it is intended to be used**.

---

## How this documentation is organized

This documentation is structured to guide you progressively:

- **Home** — high-level overview and architectural vision
- **Concepts** — core building blocks and mental model
- **Getting Started** — first execution and onboarding
- **Configuration** — execution and environment control
- **Guides** — complete real-world examples
- **Probato Manager** — observability and metrics

---

## Recommended path

If you are new to Probato, we recommend the following order:

1. Overview
2. Conceptual Architecture
3. Concepts
4. Getting Started
5. Guides

This ensures a smooth learning curve and proper understanding of the framework philosophy.
