# Getting Started

This section helps you run your **first Probato test** as quickly as possible.

The goal here is not to explain every concept in detail, but to provide a **guided path** from a clean environment to a successful test execution.

If you want to understand the framework deeply, we recommend reading the **Concepts** section first.

---

## What you will do

In this guide, you will:

1. Prepare your environment
2. Create a basic project structure
3. Configure Probato
4. Execute your first test

By the end, you will have a working Probato setup running locally.

---

## Prerequisites

Before starting, make sure you have:

- Java JDK 17 or later
- Maven 3.8+
- A supported browser (Chrome or Firefox)
- Basic knowledge of Java and automated testing

---

## Recommended reading

If you are new to Probato, these sections are especially important:

- **Concepts** → to understand the framework model
- **Test Suite** → to understand how tests are organized
- **Test Script** → to understand scenarios
